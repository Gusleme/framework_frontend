# Aula 02 - Configuração do Ambiente de Desenvolvimento

## Resumo da Aula

Esta aula aborda a configuração do ambiente de desenvolvimento, versionamento de código e ferramentas essenciais para projetos Front-end.

### 📋 Conteúdo Programático

- Introdução ao Versionamento
- Versionamento Semântico (SemVer)
- Git e Controle de Versão
- Tags, Branches e Boas Práticas no Git
- IDE e Visual Studio Code
- Node.js e NPM
- Criação de Projetos React
- Deploy e Hospedagem com Vercel

### 🔄 Versionamento x Backup

| Aspecto | Versionamento | Backup |
|---------|--------------|--------|
| Histórico | Completo, com data e autor | Cópia pontual |
| Rastreabilidade | Quem, quando e por quê mudou | Sem rastreio de autoria |
| Colaboração | Simultânea, com merge | Arquivo único |
| Reversão | Granular | Restauração total |

### 📊 Versionamento Semântico (SemVer)

Padrão `MAJOR.MINOR.PATCH`:
- **MAJOR**: Mudanças incompatíveis com versões anteriores (ex: 2.0.0)
- **MINOR**: Novas funcionalidades retrocompatíveis (ex: 1.1.0)
- **PATCH**: Correção de bugs sem alteração na API (ex: 1.0.1)

### 🛠️ Ferramentas Abordadas

- **Git**: Sistema de controle de versão distribuído
- **Visual Studio Code**: IDE recomendada
- **Node.js e NPM**: Runtime e gerenciador de pacotes
- **React**: Biblioteca para criação de interfaces
- **Vercel**: Plataforma de deploy e hospedagem

### ✅ Benefícios do Versionamento

- Trabalho simultâneo sem sobrescrever alterações
- Identificação precoce de conflitos
- Auditoria e rastreabilidade completas
- Recuperação de versões anteriores com segurança
