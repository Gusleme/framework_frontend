# Aula 01 - Apresentação da Disciplina e Contextualização

## Resumo da Aula

Esta aula apresenta a disciplina de Frameworks Front-end, seu contexto, objetivos e estrutura do semestre.

### 📋 Conteúdo Programático

- Apresentação da disciplina e plano de ensino
- Contexto da disciplina no mercado
- Sequência dos conteúdos do semestre
- Metodologia de ensino
- Critérios de avaliação

### 🎯 Objetivos da Disciplina

- Compreender o papel do Front-end na arquitetura de software
- Aprender sobre frameworks e bibliotecas modernas
- Desenvolver projetos práticos com ferramentas do mercado

### 📌 Contexto

O Front-end é a camada de interação direta com o usuário, responsável por:
- Criação de interfaces
- Organização visual
- Experiência do usuário (UX)
- Comunicação com sistemas de processamento de dados

Boa parte das aplicações web modernas utilizam frameworks Front-end para garantir interfaces rápidas, organizadas e fáceis de manter.
