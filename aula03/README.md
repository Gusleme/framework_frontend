# Aula 03 - Projetos com Frameworks Front-end

## Resumo da Aula

Esta aula introduz os principais frameworks Front-end do mercado, suas diferenças, características e aplicações práticas.

### 📋 Conteúdo Programático

- Introdução aos Frameworks Front-end
- Framework × Biblioteca
- React, Vue, Angular e Next.js
- Comparação entre Frameworks
- Criação e estrutura de projetos
- Git e versionamento

### 🏗️ O que é um Framework Front-end?

Conjunto de ferramentas, bibliotecas e convenções que padronizam o desenvolvimento de interfaces web, proporcionando estrutura pré-definida e acelerando a criação de aplicações complexas.

### 🔄 Framework × Biblioteca

| Aspecto | Framework | Biblioteca |
|---------|-----------|------------|
| Controle de fluxo | Inversão de controle (framework decide) | Você controla quando chamar |
| Estrutura | Exige estrutura definida | Flexível, sem imposições |
| Exemplos | Angular, Vue | React, jQuery |

### 🚀 Principais Frameworks

**React** (Facebook)
- Biblioteca JavaScript para interfaces de usuário
- Componentes reutilizáveis
- Virtual DOM para performance

**Angular** (Google)
- Framework completo para SPAs
- Soluções robustas e enterprise-ready

**Vue.js**
- Framework progressivo
- Fácil adaptação conforme crescimento do projeto

**Next.js**
- Framework React com funcionalidades avançadas
- SSR, SSG e roteamento automático

### ✨ Características dos Frameworks

- **Componentização**: Componentes independentes e reutilizáveis
- **Programação Reativa**: Atualização automática da UI com mudanças de estado
- **Ferramentas de Build**: Minificação, transpilação e bundling
- **Sistema de Rotas**: Navegação SPA sem recarregar a página
- **Integração com APIs**: Chamadas assíncronas e gerenciamento de estado
- **Documentação e Comunidade**: Material extenso e suporte ativo

### 💡 Por que Utilizar um Framework?

- Produtividade aumentada com soluções prontas
- Código organizado seguindo padrões reconhecidos
- Manutenção facilitada com otimizações internas
- Comunidade ativa com plugins e soluções prontas
