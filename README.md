# 📚 Backend Notes

Repositório dedicado aos meus estudos de Back-end, reunindo resumos das aulas, anotações e materiais de apoio da disciplina de Frameworks Back-end.

## 🎯 Objetivo

Organizar o conteúdo estudado, facilitar revisões e documentar minha evolução no desenvolvimento Back-end ao longo da disciplina.

## 📂 Estrutura

```
backend-notes/
├── README.md
├── Aula 01/
│   └── resumo.md
├── Aula 02/
│   └── resumo.md
├── Aula 03/
│   └── resumo.md
└── ...
```

Cada pasta representa uma aula e contém um resumo em Markdown (`.md`) com os principais conceitos abordados.
